# 中野区長選挙 期日前投票状況 可視化ダッシュボード

中野区長選挙の期日前投票状況を日別に可視化・比較するダッシュボードです。  
前回の投票状況（令和4年）と今回の投票状況（令和8年）をグラフィカルに比較し、投票ペースや投票所別の状況、性別比率などを直感的に把握できます。

本ダッシュボードは HTML、CSS、JavaScript のみで構成された**静的ウェブアプリケーション**です。サーバーサイドのプログラムは不要なため、GitHub Pages などの静的サイトホスティングサービスで簡単に公開できます。

## 主な機能
1. **日別投票者数の比較（前回 vs 今回）**: 棒グラフによる各日の投票者数比較。
2. **累計投票者数の比較（前回 vs 今回）**: 折れ線グラフによる累積ペースの比較。
3. **投票場所別の投票比率**: 各期日前投票所（区役所、すこやかセンター、区民活動センターなど）ごとの投票数と全体比の比較。
4. **性別投票者数推移（今回のみ）**: 男性の投票数と女性の投票数の日別・累計推移。
5. **インタラクティブなフィルタリング**: 投票所を選択することで、グラフとデータ詳細テーブルが瞬時に再計算されます。
6. **CSVダウンロード機能**: 表示されている詳細データをCSV形式でダウンロード可能。
7. **ダーク・ライトテーマ切り替え**: モダンなグラスモーフィズムデザインで、テーマを動的に切り替え可能。

## ファイル構成
* `index.html`: ダッシュボードのメイン構造。SEO・レスポンシブ対応。
* `styles.css`: デザインシステム、カラーパレット（ダーク/ライト）、アニメーション、レイアウト。
* `data.js`: 中野区公式発表のPDFから抽出した投票データ（自動更新対象）。
* `app.js`: データの集計、Chart.js を用いたグラフの描画、各種計算、テーマ切り替えなどのインタラクション。
* `update_data.py`: 中野区HPから最新の速報PDFを自動ダウンロード・解析し、`data.js` を更新するスクリプト。
* `.github/workflows/auto_update.yml`: 毎日 21:15 JST にスクリプトを実行し、更新データをGitHubに自動プッシュする設定ファイル。
* `server.py`: ローカルでダッシュボードを起動・検証するための簡易 Python サーバー。
* `0602kutyou.pdf` / `0603kutyou.pdf`: 出典元の中野区長選挙 期日前投票日計表PDF。
* `parse_pdf.py` / `parse_data.py`: PDFからテキストデータを抽出・検証するための開発用スクリプト。

## ローカルでの実行方法
Python がインストールされている環境であれば、以下の手順でローカルサーバーを起動し、ブラウザで確認できます。

1. コマンドプロンプトまたはターミナルを開きます。
2. 本プロジェクトのディレクトリに移動します。
3. 以下のコマンドを実行します：
   ```bash
   python server.py
   ```
4. 自動的にブラウザが起動し、 `http://localhost:8000` でダッシュボードが表示されます。

## GitHub Pages での公開手順（静的サイトとして組み込む方法）

本ダッシュボードは静的ファイルのみで動作するため、GitHub にリポジトリを作成するだけで無料のウェブサイトとして公開できます。

### 手順 1: ローカルで Git リポジトリを初期化してコミットする
リポジトリのディレクトリで以下のコマンドを実行し、ファイルをコミットします。

```bash
# Gitリポジトリの初期化
git init

# 全てのファイルをステージング（.gitignoreで不要なファイルは除外されます）
git add .

# 初回コミット
git commit -m "feat: 初回コミット。期日前投票状況可視化ダッシュボードの実装"
```

### 手順 2: GitHub に新しいリポジトリを作成してプッシュする
1. [GitHub](https://github.com/) にログインし、右上プラスアイコンから **New repository** を選択します。
2. リポジトリ名（例：`nakano-election-dashboard`）を入力し、リポジトリを作成します（Public を選択してください）。
3. 作成後の画面に表示されるコマンドに従い、ローカルリポジトリを GitHub にプッシュします：

```bash
# ブランチ名を main に変更
git branch -M main

# リモートリポジトリの登録（URLはご自身のものに置き換えてください）
git remote add origin https://github.com/あなたのユーザー名/nakano-election-dashboard.git

# GitHubへプッシュ
git push -u origin main
```

### 手順 3: GitHub Pages を有効化する
1. GitHub 上のリポジトリページにアクセスし、上部メニューの **Settings**（設定）をクリックします。
2. 左側サイドバーから **Pages**（ページズ）をクリックします。
3. **Build and deployment** セクションの **Source** で `Deploy from a branch` が選択されていることを確認します。
4. **Branch** で `main` ブランチを選択し、フォルダを `/ (root)` に設定して、**Save**（保存）ボタンをクリックします。

### 手順 4: 公開ページの確認
設定保存後、約1〜2分でデプロイが完了します。
GitHub Pages の設定画面上部に、以下のような公開URLが表示されます：
`https://あなたのユーザー名.github.io/nakano-election-dashboard/`

このURLにアクセスすると、ダッシュボードがインターネット上に公開されているのを確認できます。他の静的サイト（既存のブログやホームページなど）に組み込みたい場合は、このURLを `<iframe>` タグなどでリンクするだけで簡単に埋め込むことが可能です。

## データの自動更新設定（GitHub Actions）

本リポジトリには、中野区HPから毎日自動で最新データを取得して更新する自動化ワークフローが組み込まれています。これを正しく動作させるためには、以下の設定を GitHub上で行ってください。

### 必須設定: ワークフローの書き込み権限の有効化
GitHub Actions が自動でデータ（`data.js`）を書き換えてリポジトリにプッシュできるように、リポジトリの設定を変更します。

1. GitHub リポジトリの上部メニューから **Settings**（設定）を開きます。
2. 左側サイドバーの **Actions** から **General** をクリックします。
3. ページ最下部までスクロールし、**Workflow permissions**（ワークフローの権限）セクションを探します。
4. **Read and write permissions**（読み取りおよび書き込み権限）にチェックを入れます。
5. **Save**（保存）ボタンをクリックします。

### 動作の流れ
* **自動実行**: 毎日 **21:15 JST (12:15 UTC)** に GitHub Actions が自動で実行され、中野区の投票所速報ページから新しいPDFを検知してダウンロードします。データが更新された場合のみ、自動で `data.js` を書き換えてコミット・プッシュします。これにより GitHub Pages も自動的に更新されます。
* **手動実行**: リポジトリの **Actions** タブから `Daily Election Data Auto-Update` を選択し、**Run workflow** ボタンをクリックすることで、任意のタイミングで手動アップデートを行うことも可能です。
